🧭 Conselia — Tu Asesor Personal e Inspirador con IA

Conselia es una aplicación web moderna e interactiva diseñada para ofrecer consejos personalizados, mentoría continua en tiempo real y herramientas de toma de decisiones, todo impulsado por la API de Google Gemini.

✨ Características Principales

💡 Explorador de Consejos Personalizados: Genera guías y planes de acción por categorías (Carrera, Finanzas, Salud & Mente, Relaciones, Productividad y Estudios) con diferentes tonos (Empático, Directo, Motivador, Filosófico, Estratégico).

💬 Mentor Virtual (Chat Continuo): Un asistente de conversación en tiempo real para profundizar en tus dilemas paso a paso.

⚖️ Matriz Evaluadora de Decisiones: Sopesa pros y contras entre dos o más opciones con un dictamen analítico impulsado por IA.

🎨 Generador de Tarjetas Ilustradas: Crea imágenes artísticas e inspiracionales para acompañar tus reflexiones usando generación de imágenes con Gemini.

🔊 Lectura por Voz (Text-to-Speech): Escucha tus consejos directamente desde el navegador.

📑 Guardados & Biblioteca: Guarda tus consejos favoritos localmente para consultarlos cuando quieras.

🛠️ Tecnologías Utilizadas

Frontend: HTML5, Tailwind CSS, FontAwesome Icons.

Lenguaje: JavaScript ES6+ (Vanilla JS).

Motor de IA: API de Google Gemini (gemini-3-flash, gemini-3.1-flash-lite-image).

Renderizado de Texto: Marked.js (Markdown parser).
